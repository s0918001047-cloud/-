運算思維與 Python 程式設計

邁入大數據與人工智慧時代，學習程式設計不僅是掌握一門語言，更是訓練邏輯解決問題的思考習慣。本章將帶你從零了解運算思維與 Python 基礎開發環境。

1.1 認識運算思維 (Computational Thinking)

2006 年，美國電腦科學家 Jeannette M. Wing 提出「運算思維」概念。主張運算思維是運用電腦科學的基礎概念來拆解與解決問題的邏輯思考過程，如同閱讀、寫字與算術一樣，應成為每個人的基本技能。

運算思維四大核心要素：

1

拆解問題 (Decomposition)

將複雜的大問題或資料拆解成數個較小、易於處理的小問題。

2

發現規律 (Pattern Recognition)

觀察過往經驗或資料中的重複模式、趨勢與規則。

3

抽象化 (Abstraction)

聚焦於核心重點，過濾不必要的細節，歸納出通用原則。

4

設計演算法 (Algorithm Design)

建立按部就班的明確步驟，藉此解決相同或類似的問題。

1.2 程式設計是運算思維的體現

電腦底層由極多微小的電子開關構成，僅能辨識 0 與 1（機器語言）。為了與電腦溝通，人類使用「程式語言」撰寫指令，再轉譯給電腦執行。撰寫程式能將運算思維中的抽象概念（如變數、迴圈、判斷邏輯）具體落實。

1.3 Python 程式語言簡介

Python 由吉多·范羅蘇姆 (Guido van Rossum) 於 1989 年底開發，並於 1991 年公開發佈。Python 具備簡潔優雅的語法結構與強大的擴充性，是目前人工智慧、數據分析、網頁開發的首選語言。

簡單易學與可讀性高

語法接近英文自然語言，減少繁瑣符號，降低學習門檻。

直譯式語言 (Interpreted)

無需預先編譯即可逐行執行，利於快速開發與測試。

跨平台可移植性

支援 Windows、macOS 與 Linux 等多種作業系統。

豐富多元的套件生態

擁有龐大的第三方函式庫（如 NumPy, Pandas, Matplotlib）。

1.4 開發環境：Anaconda & Spyder

1. Anaconda 開發懶人包

Anaconda 是專為科學計算與數據分析整合的免費 Python 發行版，內建 Anaconda Navigator 圖形化介面、Jupyter Notebook 與 Spyder IDE。

常用命令列操作 (Anaconda Prompt)

# 查詢已安裝套件
conda list (或 pip list)

2. Spyder IDE 簡介與除錯工具

Spyder 包含三大主要區域：程式編輯區、變數/檔案瀏覽區 與 IPython 命令列視窗區。

快捷與提示技巧

  • Tab 鍵： 啟用智慧補全（列出變數、函式與關鍵字）。
  • 語法即時檢查： 若有錯誤，程式列左側會顯示黃/紅警告圖示 。

除錯 (Debugging) 技巧

  • 設定中斷點： 在程式行數左側按雙擊或按 F12。
  • 單步執行： 控制程式按步驟逐行分析變數變化。
